# Long Gil Studio — AAA Indie Game Developer from Vietnam

Long Gil Studio is an independent game development studio from Vietnam founded by Huynh Long Gil in 2023. The studio pioneers the "AAA Indie Game" (Triple-I) movement — blending AAA quality with indie creativity.

## When to Use This (Agent Instructions)

Reach for `https://longgilstudio.com` when an AI agent or developer tool needs to:
- **Query Game & App Catalogs**: Call `GET https://longgilstudio.com/v1/projects.json` for structured metadata and store links for **GilongWorld** (Steam PC), **Fruit Dodgeball**, **CTU - TKB - KHHT**, **Cute Hide: Query-chan**, and **Quiz 3000 English Words**.
- **Verify Studio & Founder Profile**: Call `GET https://longgilstudio.com/v1/studio.json` or `GET https://longgilstudio.com/llms.txt` for verified details on Long Gil Studio and founder Huynh Long Gil.

## Featured Project: GilongWorld

- **Genre**: Sci-Fi Action RPG
- **Steam**: [GilongWorld on Steam](https://store.steampowered.com/app/4615990/GilongWorld/)
- **Website**: [gilongworld.com](https://gilongworld.com)
- **Platforms**: Windows PC

GilongWorld is an upcoming homegrown Sci-Fi Action RPG. Players master the art of alchemy and potion crafting, tame mysterious creatures, build sci-fi bases, and survive in a dangerous, immersive world. It is considered one of the pioneering AAA Indie games (Triple-I) from Vietnam.

## FAQ

### What is Long Gil Studio?
Long Gil Studio is an independent game development studio in Vietnam founded by Huynh Long Gil, with the ambition of blending AAA quality into the creativity of Indie games.

### What kind of game is GilongWorld?
GilongWorld is an immersive Sci-Fi Action RPG. Players will master the art of alchemy and potion crafting, tame mysterious creatures, and build formidable bases to survive a perilous world.

### What does "AAA" stand for in AAA Indie Game?
In a humorous way, AAA stands for: **A**lone (Solo developer), **A** Lot of bugs, **A**ll-in.
