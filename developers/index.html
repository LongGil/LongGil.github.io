Long Gil Studio Developer Portal & Agent Hub

Welcome to the official Developer Portal for Long Gil Studio. Integrate AI agents, scripts, and developer tools with our REST API v1, OpenAPI 3.1 specification, interactive sandbox environment, and official CLI tool.

1. Quickstart Guide

Query the Long Gil Studio REST API v1 directly over HTTPS or request Markdown content negotiation on any page:

Fetch Studio Metadata & Projects (REST API v1)

# 1. Fetch studio profile, founder metadata, and versioning status
curl -sS https://longgilstudio.com/v1/studio.json \
  -H "Accept: application/json" \
  -H "X-API-Version: v1"

# 2. Fetch catalog of games and apps (GilongWorld, Fruit Dodgeball, CTU-KHHT, Cute Hide, Quiz 3000)
curl -sS https://longgilstudio.com/v1/projects.json \
  -H "Accept: application/json" \
  -H "X-API-Version: v1"

# 3. Request homepage as clean Markdown via Content Negotiation
curl -sS -L -H "Accept: text/markdown" https://longgilstudio.com/

2. Authentication & API Keys

All public discovery and catalog endpoints (GET /v1/studio.json, GET /v1/projects.json, GET /openapi.json, GET /llms.txt) support unauthenticated read access (auth.type: "none") so autonomous AI agents can query them immediately without credential friction.

Sandbox API Key (For Agent & Client Testing)

For testing authenticated agent workflows, header forwarding, or sandbox integrations, pass the public sandbox API key in either the X-API-Key or Authorization: Bearer header:

  • Public Sandbox API Key: lgs_sandbox_demo_key_v1
  • Header Format: X-API-Key: lgs_sandbox_demo_key_v1 or Authorization: Bearer lgs_sandbox_demo_key_v1
  • Dedicated Partner Keys: Request higher rate limits or partner webhook keys via info@longgilstudio.com.

3. Sandbox Environment & Live API Explorer

Agents and developers can test integrations safely against our sandbox endpoint (https://longgilstudio.com/v1/sandbox.json) or by sending the X-Sandbox-Mode: true header to any endpoint. 

// Click "Run Sandbox Request" to inspect live response headers and JSON body.
{
  "sandbox": "ready",
  "endpoint": "https://longgilstudio.com/v1/sandbox.json",
  "api_key": "lgs_sandbox_demo_key_v1"
}

4. Official CLI Tool (@longgilstudio/cli)

Script interactions with Long Gil Studio from terminal environments or autonomous coding agents without writing boilerplate HTTP requests.

Installation & Usage (npm / PyPI / Homebrew)

# Run directly via npx (Node.js / npm)
npx @longgilstudio/cli info
npx @longgilstudio/cli projects --format json

# Or install globally via npm, PyPI, or Homebrew
npm install -g @longgilstudio/cli
pip install longgilstudio
brew install longgilstudio/tap/lgs

# Direct standalone Node.js ESM script from longgilstudio.com
curl -sS https://longgilstudio.com/cli/lgs.mjs -o lgs.mjs && node lgs.mjs projects

CLI Package Manifest: /cli/package.json | Standalone CLI Script: /cli/lgs.mjs | GitHub: github.com/LongGilStudio

5. API Endpoints, Rate Limits & Versioning

Core Endpoints

  • GET /v1/studio.json — Studio profile, founder details, versioning & deprecation metadata.
  • GET /v1/projects.json — Complete game & application catalog with Steam, Google Play, and App Store links.
  • GET /v1/sandbox.json — Sandbox environment status and test credentials.
  • GET /openapi.json & /api/openapi.yaml — OpenAPI 3.1.0 specifications.
  • GET /llms.txt & /AGENTS.md — Agent instructions and when-to-use guidance.

Rate Limit Response Headers (IETF RateLimit)

All responses emit standard RFC rate-limit headers so agents can self-throttle in real time:

  • RateLimit-Limit: 60 / X-RateLimit-Limit: 60 — Maximum requests allowed per 60-second window.
  • RateLimit-Remaining: 59 / X-RateLimit-Remaining: 59 — Remaining requests in the current window.
  • RateLimit-Reset: 60 / X-RateLimit-Reset: 60 — Seconds until the rate-limit window resets.
  • RateLimit-Policy: 60;w=60 & RateLimit: limit=60, remaining=59, reset=60
  • Retry-After: 60 — Returned alongside HTTP 429 Too Many Requests when limits are exceeded.

Versioning & Deprecation Policy

Endpoints are versioned via URL path (/v1/) and header (X-API-Version: v1). Deprecated endpoints include Deprecation (RFC 9745) and Sunset (RFC 8594) headers at least 90 days before removal.
