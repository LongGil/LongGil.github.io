Long Gil Studio REST API v1 Documentation

Complete reference for the Long Gil Studio REST API v1 (https://longgilstudio.com/v1), OpenAPI 3.1 schema, authentication, rate-limit headers, and CLI tool. Visit the Developer Portal (/developers) for the interactive sandbox explorer.

Authentication

Public read-only endpoints require no authentication (auth: none). For sandbox testing, pass X-API-Key: lgs_sandbox_demo_key_v1 or Authorization: Bearer lgs_sandbox_demo_key_v1.

Endpoints & Example Requests

1. GET /v1/studio.json — Studio Metadata

curl -sS https://longgilstudio.com/v1/studio.json \
  -H "Accept: application/json" \
  -H "X-API-Version: v1"

2. GET /v1/projects.json — Games & Applications Catalog

curl -sS https://longgilstudio.com/v1/projects.json \
  -H "Accept: application/json" \
  -H "X-API-Version: v1"

3. GET /v1/sandbox.json — Sandbox Health & Echo

curl -sS https://longgilstudio.com/v1/sandbox.json \
  -H "X-API-Key: lgs_sandbox_demo_key_v1" \
  -H "X-Sandbox-Mode: true"

4. Official CLI Tool (@longgilstudio/cli)

npx @longgilstudio/cli info
npx @longgilstudio/cli projects --format json
npm install -g @longgilstudio/cli
pip install longgilstudio
brew install longgilstudio/tap/lgs

Rate Limit & Versioning Headers

Responses include RateLimit-Limit: 60, RateLimit-Remaining: 59, RateLimit-Reset: 60, RateLimit-Policy: 60;w=60, X-API-Version: v1, and Deprecation: false (plus Retry-After: 60 on HTTP 429).
